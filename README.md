# 🌐 TelzonOS

> A web-based operating system with OS-level design philosophy — not just a website.

## 🚀 Live Demo

**[👉 Open TelzonOS](https://telzonos.github.io/telzonos/)**

## ✨ Unique Features

- 🔮 **Telzon Orb** — 1/2/3 tap + long-press assistant
- 🎤 **Telzon Assistant** — Breathe animation + color system
- 💬 **TelzonAI** — Hybrid Local + Gemini AI
- 🔷 **Hexagon Icons** — Original Telzon design
- 🌊 **Telzon Flow** — Icon wave effect
- 💜 **Telzon Pulse** — Breathing background
- ⚡ **FPS-Aware System** — Auto performance popup

## 📱 Apps Included

Camera · Clock · TBrowser · TelzonAI · Calculator · Tpay · Gallery · Notes

## 🔑 Setup TelzonAI (Free)

1. Get free Gemini key: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Open TelzonAI app → ⚙️ Settings
3. Paste your key — Done!
